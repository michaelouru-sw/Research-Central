# Research Central

Moodle local plugin (`local_researchcentral`) for tracking research projects (diploma, undergraduate and postgraduate) from topic to final submission: supervision, milestones, reviews, ethics, examiners, analytics and reminders.

- Requires Moodle 5.0+
- Version 2.4.5

## Install
1. Copy the `researchcentral` folder to `<moodle>/public/local/researchcentral` (Moodle 5.1: `public/local/`).
2. Visit Site administration → Notifications, or run `php admin/cli/upgrade.php`.
3. Purge caches. Open **Research Central** in the top navigation, or `/local/researchcentral/portal.php`.
